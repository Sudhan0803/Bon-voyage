# BON-VOYAGE Travel Planner

![BON-VOYAGE](https://img.shields.io/badge/BON--VOYAGE-Travel%20Planner-blue)


A comprehensive **web-based travel planning application** that helps users create, manage, and share detailed travel itineraries with interactive features and budget tracking.

---

## 🎯 Features

### 1. Login / Signup Screen
- User authentication with email/password  
- "Remember me" functionality  
- Forgot password option  
- Demo credentials for quick testing  

### 2. Dashboard / Home Screen
- Overview of travel statistics (trips, cities, days, budget)  
- Recent trips with quick actions  
- Recommended destinations  
- Quick trip creation  

### 3. Create Trip Screen
- Trip creation form (name, dates, description)  
- Travel type selection (solo, couple, family, etc.)  
- Privacy settings and cover photo upload  
- Data validation and error handling  

### 4. My Trips Screen
- Grid view of all user trips  
- Filter by status (upcoming, ongoing, completed)  
- Trip cards with essential details  
- Edit, delete, and view options  

### 5. Itinerary Builder Screen
- Drag-and-drop trip stop organization  
- Day-by-day activity planning  
- Activity details (time, duration, cost)  
- Real-time itinerary preview  

### 6. Itinerary View Screen
- Visual itinerary representation  
- Interactive map with route visualization  
- Day selector for easy navigation  
- Print and export options  

### 7. City Search Screen
- Search and filter cities by region, price, and popularity  
- City cards with ratings and cost indices  
- Add cities to existing trips  

### 8. Activity Search Screen
- Browse activities by type, price, and duration  
- Detailed activity cards  
- Add activities to specific trip days  

### 9. Trip Budget & Cost Breakdown
- Doughnut chart for budget distribution  
- Bar chart for daily spending  
- Category-wise cost breakdown  
- Budget alerts and savings tips  

### 10. Trip Calendar / Timeline Screen
- Calendar view with highlighted trip days  
- Timeline view of itinerary  
- Day-level activity details  
- Print and export calendar  

### 11. Public Itinerary View
- Shareable itinerary links  
- Read-only public view  
- Social media sharing  
- Copy trip functionality  

### 12. User Profile / Settings
- Personal information management  
- Notification preferences  
- Privacy and security settings  
- Currency and language preferences  

### 13. Admin Dashboard
- Platform analytics and statistics  
- User management  
- Content moderation  
- System logs and monitoring  

---
